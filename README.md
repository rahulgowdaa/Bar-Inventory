# Bar Inventory

A simple inventory management system for bars, designed to help track stock levels, manage products, and streamline operations.

## Features

- Add, edit, and remove inventory items
- Track stock levels and receive low-stock alerts
- Categorize products (e.g., spirits, mixers, garnishes)
- Generate inventory reports

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/Bar-Inventory.git
    cd Bar-Inventory
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the application:
    ```bash
    npm start
    ```

## Usage

- Access the dashboard to view and manage your inventory.
- Use the "Add Item" button to add new products.
- Edit or delete items as needed.
- Monitor stock levels and restock when necessary.
